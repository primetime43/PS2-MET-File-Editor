# Backyard Baseball PS2 Editor v1.0.0

This is the first stable release of the focused Backyard Baseball editor for PlayStation 2.

## Download and requirements

Download `Backyard-Baseball-PS2-Editor-v1.0.0-win-x64.zip`, extract it, and run
`Backyard Baseball PS2 Editor.exe`. The release is self-contained for Windows x64 and does not require
a separate .NET installation.

Use your own extracted Backyard Baseball (USA) game files. ImgBurn is required only when rebuilding an
ISO from inside the editor.

## Highlights

- Edit all retail and clone player stats, names, identity fields, pitch ratings, biographies, portraits,
  animated selection images, and textured 3D player appearances.
- Edit stadium lighting, cameras, collisions, ambient objects, paths, animations, and the actual 3D
  home-run boundary with a joined textured preview.
- Tune 285 gameplay and physics values or use presets for ball size, bounce, rolling, hitting, bunts,
  power-ups, catching, and complete game styles.
- Reconfigure teams and divisions and edit all 40 season schedule templates.
- Preview and edit RenderWare animations and EVT lip-sync/facial timelines on textured player models.
- Browse and export RenderWare DFF/RWS models, stadiums, embedded textures, PS2 audio, and raw DATA.MET assets.
- Unlock game content and enable recovered retail developer options through guarded executable patches.
- Rebuild a playable modded ISO directly from the extracted game folder.

## Compatibility and safety

DATA.MET browsing and structured archive editors target the retail USA game data. Executable patches
specifically require the verified USA `SLUS_208.65`; another revision or a conflicting instruction patch
is rejected before writing.

DATA.MET, executable, ISO, and exported-save changes create timestamped backups where applicable.
Replacement textures, VAG audio, and PSS video are validated before import.

The release includes a `.sha256` file beside the ZIP so the downloaded archive can be verified with
PowerShell:

```powershell
Get-FileHash .\Backyard-Baseball-PS2-Editor-v1.0.0-win-x64.zip -Algorithm SHA256
```
